# Dashboard 数据口径规则

- API 直传数据由前端按契约展示，不重复舍入；前端派生的百分比/比值在显示边界格式化，避免浮点长尾。
- 动画插值精度跟随目标值，不直接呈现未格式化的中间值。
- 调度器状态与查询参数以 driver 实现和测试为唯一事实源。新增/修改状态映射时同步更新对应测试；全局作业查询须包含调度器要求的全用户范围参数。
- 节点注册/在线数量与可用资源统计不可混用。资源聚合排除非在线节点及已移除节点的残留报表；字段和新鲜度条件以 dashboard 查询实现与测试为准。
