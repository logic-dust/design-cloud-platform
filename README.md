# Design Cloud Platform

> 面向集成电路（EDA/IC）、机械结构（CAE）、计算流体力学（CFD）及工业设计（CAD）的企业级云化研发工作台与集群算力协同平台。

---

## 一、 产品概述与定位

**Design Cloud Platform** 是一套专为**工业工程研发与复杂仿真计算（EDA / CAE / CFD / CAD）**场景打造的企业级研发云平台。

平台通过统一的控制平面（`Design Cloud Engine`）与现代化的原生工作台客户端（`Design Cloud Desktop`），将底层的异构计算集群、图形工作站、分布式存储与工程软件资产深度整合，为研发工程师提供极致流畅的远程交互与作业调度体验，同时为企业提供严密的三员分权、数据流转审计与工业资产治理能力。

## 二、 核心设计理念

### 1. 坚持原生交互品质，满足工业前后处理的极限要求
无论是二维纳米级芯片版图的精细平移，还是千万级有限元网格（FEA）的旋转剖分、复杂三维流场（CFD）的动态云图渲染，工业级前后处理对帧率稳定性、色彩保真度、3D 加速及快捷键响应有着严苛标准。
* **设计抉择**：平台确立了**“控制面云端统一调度，交互面原生桌面闭环”**的架构路线。
* **业务价值**：通过桌面端原生图形引擎与系统级接入，实现无损渲染、全局快捷键透传、双屏/三屏 4K 拓展与极低交互延迟，彻底消除浏览器沙箱带来的掉帧与快捷键冲突，提供原汁原味的本地工作站体验。

### 2. 双轨生命周期解耦：交互工作台与求解器算力池正交治理
在复杂工程研发中，工程师需要常驻桌面进行模型装配、网格调整与后处理（模型加载常需数十分钟，不可随意中断）；同时又需要频繁调用底层求解器（Solver）向集群提交耗费海量核时的仿真作业。
* **设计抉择**：
  * **交互常驻工作台（Fixed Workspace）**：采用“固定节点 + 系统级资源弹性上限（cgroup）”治理模式。工作台在用户思考、开会或离开时自动让出算力，不刚性占死集群排队 Slot；免去因队列超时被强制杀进程而导致设计成果丢失的风险。
  * **批处理仿真计算（Batch/Simulation Jobs）**：由底层集群调度器统筹排队分发；作业运行期间产生的临时查看界面（如求解收敛曲线、临时 GUI）通过标准通道即时接入，随作业结束自动释放。
* **业务价值**：兼顾了工程师研发交互的连续性与企业昂贵算力资源利用率的极致化。

### 3. 开放协议编排，规避专有协议锁定
* **设计抉择**：平台不自研私有封闭的远程流媒体协议，而是将成熟开放的工业标准（VNC、RDP、SSH）作为底层基础设施。平台聚焦于**连接事实维护、安全代理穿透（OTP 鉴权）、生命周期自动化管控与分布式探针编排**。
* **业务价值**：企业无需为每个工程师席位支付昂贵的专有协议商业授权，具备极高的横向扩展性与平滑兼容能力。

### 4. 数据主权与企业级“三员分立”安全底座
工程图纸、三维模型、材料参数与源代码是制造业与高科技企业的核心知识产权（IP）。
* **设计抉择**：内置**系统管理员（System Admin）、安全保密员（Security Admin）、安全审计员（Audit Admin）**三权分立与互相制约架构，任何单一角色均无法越权。
* **业务价值**：所有远程访问均受 OTP 与网关管控，所有敏感操作（文件上下行、权限变更、会话控制）全量记录审计，全面满足国家标准与行业等保密评要求。

## 三、 六大核心功能体系

#### 1. 混合远程桌面与连接治理 (Remote Access Governance)
* **多协议集中纳管**：统一管理 VNC、RDP、SSH 等各类图形与字符连接资产，支持客户端直连（Direct）与安全网关（Proxy）双模式。
* **会话全生命周期管控**：支持工作台会话的一键创建、启动、休眠、恢复与销毁，底层联动 Agent 自动清理孤儿进程。
* **动态资源隔离**：通过 `cgroup` 与受控用户登录环境初始化，精确限制单个交互会话的最大内存与 CPU 上限，杜绝内存泄漏撑爆物理机的风险。

#### 2. 异构集群算力调度 (Heterogeneous Scheduler Engine)
* **多调度器抽象与统一接口**：屏蔽底层集群差异，原生适配主流工业调度器（如 LSF / Slurm 等），提供一致的作业全生命周期 API。
* **仿真全流程跟踪**：支持仿真作业参数化提交、批量控制（终止、暂停、恢复）、优先级调节、运行状态感知与日志实时流式查看。
* **求解与图形联动**：无缝打通求解器批处理作业与临时图形界面的回投，实现“提交求解 - 监控残差 - 交互后处理”的一站式闭环。

#### 3. 工业软件资产与 License 智能感知 (License Intelligence)
* **许可证实时监控**：深度集成工业标准 License 管理体系（FlexLM / RLM 等），实时采集、解析并呈现各 Module / Feature 的总额、已用配额、占用人员与排队情况。
* **投资回报与瓶颈分析**：直观展示昂贵工业工程软件的实时使用水位与峰值趋势，为企业软件资产采购、续约谈判与分时错峰调度提供客观数据支撑。

#### 4. 安全文件流转与存储审批 (Secure File Management & Approval)
* **存储位置与挂载点隔离**：支持针对用户隔离的 `Home`、项目协作 `Project`、高速临时计算 `Scratch` 等多类型存储挂载空间。
* **工程数据管理闭环**：提供远程工程目录树浏览、文本查看编辑、断点续传、大文件分片上传下载及压缩包在线解压。
* **外发与流转审批流**：对核心设计数据、网格模型与仿真结果的下载导出建立安全审批机制，确保核心技术资产不出内网或受控流转。

#### 5. 分布式 Agent 与节点自愈网络 (Distributed Agent & Node Management)
* **节点自动注册与状态感知**：计算节点与工作站部署轻量 Agent，自动发现硬件拓扑、CPU/内存负荷、Display 端口与显卡状态并上报控制中心。
* **受控执行框架（Launcher Actions）**：控制端通过标准化动作契约下发指令（如环境初始化、桌面启停、探针收集），杜绝脆弱且危险的远程命令拼接。

#### 6. 三员分立与审计合规 (Role-Based Segregation & Compliance)
* **三员权限严格隔离**：
  * **系统管理员**：负责节点拓扑、集群配置、存储路径与系统运行维护。
  * **安全保密员**：负责用户生命周期、封禁控制（Bans）、权限范围（Scopes）及文件下载审批。
  * **安全审计员**：专职查看与导出系统审计日志，对系统管理员和安全员的操作进行独立监督。
* **实时事件与可追溯性**：基于 SSE（Server-Sent Events）向工作台全双工推送作业变动、连接状态与工单审批事件；所有操作事实均具备不可篡改的日志证据链。

| **工程交互体验** | 纯 Web 处理三维网格或大规模版图时掉帧、操作迟滞、快捷键冲突；工程师私搭端口混乱。 | **原生桌面工作台**，60 FPS 无损流畅交互，快捷键全量独占透传，多屏高刷沉浸式办公。 |
| **算力资源利用** | 交互桌面作为作业提交导致 Slot 长时间空转浪费；或者多用户争抢无管控撑爆工作站。 | **双轨正交解耦**，常驻桌面走 cgroup 弹性限额，求解计算走调度器队列，兼顾连续性与高利用率。 |
| **资产与许可证成本** | 缺乏 License 状态感知，常出现“算力空闲但缺 License”或“License 被占用却无人使用”。 | **License 全局透视与预警**，实时查看并发占用与排队，最大化提升昂贵工业软件的使用效率。 |
